# Sistema de Cadastro de Alunos

Pequeno sistema de linha de comando (CLI) desenvolvido em **Python** para gerenciar registros de alunos em memória, criado no contexto de uma atividade prática de **Gerência de Configuração de Software**.

## Funcionalidades

- **Cadastrar aluno:** Registra nome, idade e curso de um novo aluno.
- **Listar alunos:** Exibe todos os alunos cadastrados ou informa caso a lista esteja vazia.
- **Consultar aluno:** Busca um aluno pelo nome (sem diferenciar maiúsculas e minúsculas) e exibe seus dados.
- **Excluir aluno:** Remove um aluno cadastrado a partir do nome informado.
- **Sair:** Encerra a execução do sistema.

## Como executar

Certifique-se de ter o **Python 3** instalado na sua máquina e execute:

```bash
python main.py
